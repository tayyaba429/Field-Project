About the Portal

The Campus Lost & Found Portal is a digital system that helps students report lost and found items and makes it easier to return items to their rightful owners.

Key Features

📱

Report Lost

Report your lost belongings with details, location and image.

📦

Report Found

Submit details of items found on campus to the security desk.

🔍

Smart Matching

JavaScript-based matching helps identify possible lost and found item matches.

🔐

Secure Handover

A 4-digit verification code helps ensure secure item handover.

How It Works

1

Report

Report a lost or found item.

2

Search & Match

Search items or find possible matches.

3

Claim

Submit a claim for your lost item.

4

Handover

Verify the 4-digit code and collect your item.

Portal Users

👨‍🎓 Student

Report lost/found items, search items, submit claims and receive notifications.

🛡️ Security Staff

Receive found items, verify claims, manage storage and complete handovers.

👨‍💼 Admin

Manage users, reports, claims and view returned-item analytics.
